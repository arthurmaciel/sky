Course 1 · from newcomer to developer The Sky → Rust Backend

How does a pure-functional Sky program become a native Rust binary? This course answers that end to end — first the history of how the backend was built, then a step-by-step trace of the compiler, with two worked examples for every program shape.

When you finish, you can…

  • narrate the backend's history in clear phases — runtime, codegen wiring, FFI, the backends (Live/Tui/Webview), perf, CI;
  • trace any Sky program through parse → canonicalise → type-solve → codegen → cargo, naming the functions and files;
  • explain the common path and the corner cases for each shape, and read the codegen confidently enough to change it.
