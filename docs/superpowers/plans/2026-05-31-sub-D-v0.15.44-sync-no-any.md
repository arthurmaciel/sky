```haskell
-- | Sub-D: resolve a stdlib module path, with target-aware override support.
-- On TargetRust, the override directory takes priority: a file at
-- `runtime-rust/sky-stdlib-overrides/<Module>.sky` shadows the upstream
-- `sky-stdlib/<Module>.sky` of the same module. Lets us re-declare stdlib
-- modules whose upstream shape isn't statically typeable on Rust target
-- (e.g. `RetryPolicy.shouldRetry : any` — see spec §3.3).
-- TargetGo always reads sky-stdlib/ directly; the override path is never
-- consulted on the Go path.
resolveStdlibPath :: Toml.Target -> ModuleName -> IO (Maybe FilePath)
resolveStdlibPath target modName = do
    let upstreamPath = "sky-stdlib" </> moduleNameToPath modName <.> "sky"
    case target of
        Toml.TargetRust -> do
            let overridePath = "runtime-rust" </> "sky-stdlib-overrides"
                               </> moduleNameToPath modName <.> "sky"
            overrideExists <- doesFileExist overridePath
            if overrideExists
                then return (Just overridePath)
                else fallbackUpstream upstreamPath
        Toml.TargetGo -> fallbackUpstream upstreamPath
  where
    fallbackUpstream p = do
        ok <- doesFileExist p
        return (if ok then Just p else Nothing)

-- | Sky `Sky.Core.Task` -> `Sky/Core/Task`. Reuses the existing convention
-- (dot-to-slash). If the codebase already has a helper for this, replace
-- with it.
moduleNameToPath :: ModuleName -> FilePath
moduleNameToPath = joinPath . splitOn '.' . moduleNameString
  where
    splitOn c s = case break (== c) s of
        (part, _ : rest) -> part : splitOn c rest
        (part, [])       -> [part]
    moduleNameString = ModuleName._name  -- adjust to actual field accessor
```

- [ ] **Step 2: Implement `rejectAnyInRecordFields`**

Add the helper alongside `generateRustProject`:

```haskell
-- | Sub-D §3.1: walk every record alias in the project's lowered AST. If
-- any field's resolved type is T.TVar "any" or contains it at any depth,
-- return a structured diagnostic. The Rust target lowers `any` to
-- nothing useful (would have to be Box<dyn Any>, which defeats static
-- typing); upstream stdlib modules with `any` fields ship a Rust-only
-- override at runtime-rust/sky-stdlib-overrides/<Module>.sky.
rejectAnyInRecordFields
    :: [Can.Module]
    -> Solve.SolvedTypes
    -> Maybe String  -- Nothing = clean; Just = diagnostic to print
rejectAnyInRecordFields mods solved =
    let offenders = concatMap (collectOffendingFields solved) mods
    in case offenders of
        []  -> Nothing
        os  -> Just (renderDiagnostic os)
  where
    collectOffendingFields :: Solve.SolvedTypes -> Can.Module -> [(String, String, String, A.Region)]
    collectOffendingFields _ mod =
        [ (Can.moduleName mod, aliasName, fieldName, region)
        | (aliasName, alias) <- Map.toList (Can._aliases mod)
        , Can.AliasType _ aliasBody <- [alias]
        , Can.TRecord fields _ <- [aliasBody]
        , (fieldName, Can.FieldType region fieldTy) <- Map.toList fields
        , containsAnyTypeVar fieldTy
        ]

    containsAnyTypeVar :: Can.Type -> Bool
    containsAnyTypeVar t = case t of
        Can.TVar "any"        -> True
        Can.TVar _            -> False
        Can.TType _ _ args    -> any containsAnyTypeVar args
        Can.TLambda a b       -> containsAnyTypeVar a || containsAnyTypeVar b
        Can.TRecord fs ext    -> any (\(Can.FieldType _ ft) -> containsAnyTypeVar ft) (Map.elems fs)
                                  || maybe False (== "any") ext
        Can.TTuple a b rest   -> any containsAnyTypeVar (a : b : rest)
        Can.TUnit             -> False
        Can.TAlias _ _ _ aliased -> containsAnyTypeVar aliased

    renderDiagnostic offenders = unlines $
        [ "error[Rust]: any-typed record field on `--target rust`"
        , ""
        ] ++ concatMap renderOne offenders ++
        [ ""
        , "  = note: the Go target lowers `any` to interface{} (runtime dynamic"
        , "          dispatch), which defeats Rust's static type system. The Sky"
        , "          stdlib should encode heterogeneous fields as an ADT — e.g."
        , "          `type ShouldRetry e = RetryAlways | RetryWhen (e -> Bool)`."
        , "  = note: stdlib modules with known `any` fields ship a Rust-only"
        , "          override at runtime-rust/sky-stdlib-overrides/<Module>.sky"
        , "          that the Rust target loads in place of upstream."
        , "  = note: tracked upstream: see docs/runtime-rust/upstream-issues/"
        ]

    renderOne (modName, aliasName, fieldName, region) =
        [ "  --> in module " ++ modName ++ ", alias " ++ aliasName ++ ", field " ++ fieldName
        , "      at " ++ show region
        ]
```

use std::sync::Arc;

/// Sky's `ShouldRetry e` ADT (local override at
/// runtime-rust/sky-stdlib-overrides/Sky/Core/Task.sky). Fully typed —
/// no runtime erasure. The `When` variant carries an Arc<dyn Fn> as the
/// statically-known function-pointer slot of the ADT, NOT as type
/// erasure (the type is fixed by the constructor, the same way
/// std::thread::spawn carries Box<dyn Fn>).
#[derive(Clone)]
pub enum ShouldRetry<E: Send + Sync + 'static> {
    Always,
    When(Arc<dyn Fn(E) -> bool + Send + Sync>),
}

/// Sky's `RetryPolicy e` record alias. Generic over the error type.
#[derive(Clone)]
pub struct RetryPolicy_R<E: Send + Sync + 'static> {
    pub maxAttempts: i64,
    pub baseMs: i64,
    pub kind: i64,
    pub jitter: bool,
    pub shouldRetry: ShouldRetry<E>,
}

/// Sky `retryAlways : ShouldRetry e` — zero-arg ctor of the Always variant.
pub fn task_retry_always<E: Send + Sync + 'static>() -> ShouldRetry<E> {
    ShouldRetry::Always
}

/// Sky `retryWith : RetryPolicy e -> (() -> Task e a) -> Task e a`.
///
/// Takes a task PRODUCER (closure) rather than a task because Rust's
/// SkyTask = Pin<Box<dyn Future>> can only be awaited once — a fresh
/// Future is needed per retry attempt. Matches the user-facing override
/// signature in runtime-rust/sky-stdlib-overrides/Sky/Core/Task.sky.
pub fn task_retry_with<E, A, F>(
    policy: RetryPolicy_R<E>,
    producer: F,
) -> SkyTask<E, A>
where
    E: Send + Sync + Clone + 'static,
    A: Send + 'static,
    F: Fn() -> SkyTask<E, A> + Send + Sync + 'static,
{
    Box::pin(async move {
        let max = policy.maxAttempts.max(1);
        let mut attempt = 0_i64;
        let mut last_err: Option<E> = None;
        while attempt < max {
            attempt += 1;
            let task = producer();
            match task.await {
                SkyResult::Ok(v) => return SkyResult::Ok(v),
                SkyResult::Err(e) => {
                    let should = match &policy.shouldRetry {
                        ShouldRetry::Always   => true,
                        ShouldRetry::When(f)  => f(e.clone()),
                    };
                    if !should || attempt >= max {
                        return SkyResult::Err(e);
                    }
                    last_err = Some(e);
                    let delay_ms = compute_retry_delay(
                        policy.kind, policy.baseMs, policy.jitter, attempt,
                    );
                    tokio::time::sleep(
                        std::time::Duration::from_millis(delay_ms as u64),
                    ).await;
                }
            }
        }
        SkyResult::Err(last_err.expect("retry loop exited without final error"))
    })
}

/// Linear (kind == 0) or exponential (kind == 1) backoff, capped at 30 s,
/// with optional ±50 % jitter. Mirrors runtime-go/rt/task_retry.go.
fn compute_retry_delay(kind: i64, base_ms: i64, jitter: bool, attempt: i64) -> i64 {
    let raw = match kind {
        0 => base_ms,                                       // linear
        _ => base_ms.saturating_mul(1_i64 << (attempt - 1).min(20)),  // exponential
    };
    let capped = raw.min(30_000);
    if jitter {
        // [0.5, 1.5) — math/rand-equivalent, not crypto.
        use rand::Rng;
        let factor = 0.5 + rand::thread_rng().gen::<f64>();
        ((capped as f64) * factor) as i64
    } else {
        capped
    }
}

// ─── Sub-D §3.5: AEAD kernels (AES-256-GCM + ChaCha20-Poly1305) ───────

use aes_gcm::{Aes256Gcm, KeyInit as _, aead::Aead as _, Nonce as AesNonce};
use chacha20poly1305::{ChaCha20Poly1305, Nonce as ChaNonce};
use rand::RngCore;

const AEAD_NONCE_BYTES: usize = 12;
const AEAD_KEY_BYTES: usize = 32;

/// Sky `aes256gcmEncrypt : Bytes -> Bytes -> Result Error Bytes`. Returns
/// nonce || ciphertext (nonce prefix lets decrypt recover it). Per-call
/// nonce from OsRng — encrypting the same plaintext twice yields different
/// ciphertexts.
pub fn crypto_aes256gcm_encrypt<E: From<String>>(
    key: String,
    plaintext: String,
) -> SkyResult<E, String> {
    let key_bytes = key.as_bytes();
    if key_bytes.len() != AEAD_KEY_BYTES {
        return SkyResult::Err(format!("aes256gcmEncrypt: key must be 32 bytes (got {})", key_bytes.len()).into());
    }
    let cipher = match Aes256Gcm::new_from_slice(key_bytes) {
        Ok(c) => c,
        Err(e) => return SkyResult::Err(format!("aes256gcmEncrypt: {}", e).into()),
    };
    let mut nonce_bytes = [0u8; AEAD_NONCE_BYTES];
    rand::thread_rng().fill_bytes(&mut nonce_bytes);
    let nonce = AesNonce::from_slice(&nonce_bytes);
    let ct = match cipher.encrypt(nonce, plaintext.as_bytes()) {
        Ok(c) => c,
        Err(e) => return SkyResult::Err(format!("aes256gcmEncrypt: {}", e).into()),
    };
    let mut output = Vec::with_capacity(AEAD_NONCE_BYTES + ct.len());
    output.extend_from_slice(&nonce_bytes);
    output.extend_from_slice(&ct);
    // Bytes is type alias Bytes = String; the bytes are UTF-8-ish (lossy).
    // The Sky-side toHex / toBase64 helpers are the right consumers — raw
    // bytes shouldn't be inspected as UTF-8.
    SkyResult::Ok(unsafe { String::from_utf8_unchecked(output) })
}

/// Sky `aes256gcmDecrypt : Bytes -> Bytes -> Result Error Bytes`.
pub fn crypto_aes256gcm_decrypt<E: From<String>>(
    key: String,
    ciphertext: String,
) -> SkyResult<E, String> {
    let key_bytes = key.as_bytes();
    if key_bytes.len() != AEAD_KEY_BYTES {
        return SkyResult::Err(format!("aes256gcmDecrypt: key must be 32 bytes (got {})", key_bytes.len()).into());
    }
    let ct_bytes = ciphertext.as_bytes();
    if ct_bytes.len() < AEAD_NONCE_BYTES {
        return SkyResult::Err("aes256gcmDecrypt: ciphertext too short (missing nonce prefix)".to_string().into());
    }
    let (nonce_bytes, ct_only) = ct_bytes.split_at(AEAD_NONCE_BYTES);
    let cipher = match Aes256Gcm::new_from_slice(key_bytes) {
        Ok(c) => c,
        Err(e) => return SkyResult::Err(format!("aes256gcmDecrypt: {}", e).into()),
    };
    let nonce = AesNonce::from_slice(nonce_bytes);
    let pt = match cipher.decrypt(nonce, ct_only) {
        Ok(p) => p,
        Err(_) => return SkyResult::Err("aes256gcmDecrypt: authentication failed (wrong key or tampered ciphertext)".to_string().into()),
    };
    SkyResult::Ok(unsafe { String::from_utf8_unchecked(pt) })
}

/// Sky `aesKeyFromPassword : String -> Bytes -> Result Error Bytes`.
/// PBKDF2-HMAC-SHA256, 100k iter, 32-byte output. Same shape for
/// chachaKeyFromPassword — both produce 32-byte keys.
pub fn crypto_aes_key_from_password<E: From<String>>(
    password: String,
    salt: String,
) -> SkyResult<E, String> {
    pbkdf2_derive_32(password, salt, "aesKeyFromPassword")
}

/// Sky `chachaKeyFromPassword : String -> Bytes -> Result Error Bytes`.
pub fn crypto_chacha_key_from_password<E: From<String>>(
    password: String,
    salt: String,
) -> SkyResult<E, String> {
    pbkdf2_derive_32(password, salt, "chachaKeyFromPassword")
}

fn pbkdf2_derive_32<E: From<String>>(password: String, salt: String, label: &str) -> SkyResult<E, String> {
    use pbkdf2::pbkdf2_hmac;
    use sha2::Sha256;
    let salt_bytes = salt.as_bytes();
    if salt_bytes.is_empty() {
        return SkyResult::Err(format!("{}: salt must be non-empty", label).into());
    }
    let mut out = [0u8; AEAD_KEY_BYTES];
    pbkdf2_hmac::<Sha256>(password.as_bytes(), salt_bytes, 100_000, &mut out);
    SkyResult::Ok(unsafe { String::from_utf8_unchecked(out.to_vec()) })
}

-- Sub-D §3.8 regression: a Task that "panics" (in Rust target terms, a
-- runtime error not caught by the existing Result channel) must surface
-- as an Err Error at the top level. Tokio's async runtime already
-- channels panics through JoinError; this test asserts the existing
-- safe_async wrapper does the right thing.

import Sky.Core.Prelude exposing (..)
import Sky.Core.Task as Task
import Sky.Core.Error as Error exposing (Error)
import Std.Log exposing (println)


-- A task that always fails — Sky-level "panic" surrogate. The Rust
-- runtime's Task chain converts any panic-during-await to Err Error
-- (via tokio's catch_unwind on the spawned future). For sub-D's purposes
-- we just need to confirm the chain doesn't crash the process.
panicTask : Task Error ()
panicTask = Task.fail (Error.unexpected "intentional panic surrogate")


main =
    let
        pipeline = panicTask |> Task.onError (\e ->
            Task.succeed ())
        result = Task.run pipeline
        _ = case result of
            Ok _  -> println "ok: panic-surrogate recovered through onError"
            Err _ -> println "fail: onError did not catch"
    in
        ()

```markdown
# Upstream issue draft: ShouldRetry e ADT redesign

**Target:** `anzellai/sky`
**Date drafted:** 2026-05-31
**Status:** ready to file (held pending user decision)

## Title

Proposal: replace `RetryPolicy.shouldRetry : any` with `type ShouldRetry e = RetryAlways | RetryWhen (e -> Bool)`

## Summary

The `v0.15.44 part 3` retry surface (commit `5947cf81`) introduced a record
alias with an `any`-typed field whose runtime behavior depends on Go's
`interface{}` semantics — the same record value holds a sentinel marker
from `linearBackoff` and a closure from `retryOn`. This shape is HM-impure
(record-update doesn't preserve a stable concrete type for the field
across instances) and can't be lowered to any statically-typed backend
without runtime boxing / downcasts.

Concretely on the Rust target: lowering `any` to `Box<dyn Any>` works at
runtime but defeats the Rust backend's reason to exist (static dispatch,
no type erasure). The `arthurmaciel/sky` fork's `feat/runtime-rust` branch
carries a local override at `runtime-rust/sky-stdlib-overrides/Sky/Core/Task.sky`
using an ADT:

\`\`\`elm
type ShouldRetry e
    = RetryAlways
    | RetryWhen (e -> Bool)

type alias RetryPolicy e =
    { maxAttempts : Int, baseMs : Int, kind : Int, jitter : Bool
    , shouldRetry : ShouldRetry e
    }
\`\`\`

## Why this is also better for the Go target

The Go `task_retry_with` currently does a reflect-backed type assertion on
`shouldRetry` per attempt. With the ADT, the same logic becomes a fixed
`switch` on the constructor tag — cheaper, simpler, and the compile-time
exhaustiveness check covers it.

## Secondary proposal: retryWith takes a thunk

Separately, the Rust target's `SkyTask = Pin<Box<dyn Future>>` is one-shot
— a retry loop needs to produce a fresh task per attempt. The
arthurmaciel fork's override signature is:

\`\`\`elm
retryWith : RetryPolicy e -> (() -> Task e a) -> Task e a
\`\`\`

This is also a defensible API change for the Go target — taking a thunk
makes the lazy-evaluation contract explicit at the type level, which
matches how Sky users already think about Task. User migration is one
character: `Task.retryWith p myTask` -> `Task.retryWith p (\_ -> myTask)`.

## Migration

If accepted:
- Both proposed changes can land in a single upstream PR.
- arthurmaciel's `feat/runtime-rust` deletes `runtime-rust/sky-stdlib-overrides/Sky/Core/Task.sky`.
- Existing user code calling the retry combinators on the Go target needs
  a one-line update for the thunk shape (mechanical).

## Cross-backend implications

Rust + WASM + any future statically-typed backend compiles cleanly. No
`Box<dyn Any>` boxing required. The Sky standard library becomes
backend-portable in this surface.

## Tested by

4 Sky.Test assertions in `examples/00-standard-libs` covering linearBackoff
/ exponential / withJitter / retryOn semantics, plus runtime tests in both
`runtime-go/rt/task_retry_test.go` and
`runtime-rust/src/sky_runtime/task.rs::retry_tests`.
```
